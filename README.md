Repositorio de ejercicios prácticos de Sistemas de Información Geográfica.

## Datos
- hospitales_boyaca.geojson

## Herramientas
- Git
- GitHub
- Python

## Actividades del curso

### C2 — Despliegue de servicios geográficos
Configuración del entorno de trabajo con Docker, PostGIS, GeoServer y servicios geográficos.

- Archivo de configuración: `docker-compose.yml`.

### C3 — Desplegar un mapa en Vercel
Desarrollo de un visor cartográfico interactivo con Leaflet, integrando establecimientos de salud y veredas del departamento de Boyacá.

- [Ver mapa interactivo publicado](https://curso-sig-marisela-mapa-boyaca-marisela.vercel.app/)
- Carpeta del proyecto: `Mapa-boyaca/`
- Tecnologías: Leaflet, OpenStreetMap, GeoJSON y Vercel.
